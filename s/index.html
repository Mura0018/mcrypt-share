O‘ZBEKCHA

Bu havola MCrypt bilan ochiladi. Ichidagi ma’lumot shifrlangan: bu sahifa ham, sayt serveri ham uni ko‘rmaydi.

  1. Havolani to‘liq nusxalang.
  2. MCrypt’ni oching: Sozlamalar → Ulashilganni ochish.
  3. Havolani qo‘ying. Paket kod bilan yuborilgan bo‘lsa, kodni yuboruvchidan so‘rang — u havolada emas.

MCrypt o‘rnatilmagan bo‘lsa, havolani saqlab qo‘ying: u o‘z-o‘zidan eskirmaydi.

ENGLISH

This link opens in MCrypt. What it carries is encrypted: neither this page nor the server behind it can read it.

  1. Copy the whole link.
  2. Open MCrypt: Settings → Open a shared package.
  3. Paste the link. If the package was sent with a code, ask the sender for it — the code is not in the link.
